# Предпросмотр страниц в визуальном редакторе

## 🎯 Обзор

Реализован полноценный предпросмотр готовых страниц в визуальном редакторе. Теперь пользователи могут видеть, как будет выглядеть страница с реальным контентом, а не просто блоки в режиме редактирования.

## ✨ Основные возможности

### 1. **Реалистичный предпросмотр**
- Отображение страницы как готового продукта
- Красивое оформление с градиентами и тенями
- Адаптивный дизайн для всех устройств
- Анимации и переходы

### 2. **Полная поддержка всех блоков**
- **Заголовки**: Разные уровни с правильной типографикой
- **Текст**: HTML-контент с красивым форматированием
- **Изображения**: С подписями и обработкой ошибок
- **Галереи**: Три макета (сетка, кладка, карусель)
- **Кнопки**: Стильные кнопки с эффектами
- **Формы**: Полнофункциональные контактные формы
- **Разделители**: Элегантные разделители

### 3. **Улучшенный UX**
- Индикатор режима предпросмотра
- Подсказки для пустых страниц
- Красивое оформление заголовков и подвалов
- Плавные переходы между режимами

## 🏗️ Техническая реализация

### Компонент `PagePreview`

```typescript
interface PagePreviewProps {
  pageData: PageData;
  className?: string;
}
```

**Основные функции:**
- Рендеринг всех типов блоков в предпросмотре
- Обработка ошибок загрузки изображений
- Адаптивная верстка
- Красивое оформление

### Специализированные компоненты предпросмотра

#### `HeadingPreview`
- Поддержка всех уровней заголовков (H1-H6)
- Адаптивная типографика
- Настройка выравнивания
- Красивые градиенты и тени

#### `ParagraphPreview`
- Поддержка HTML-контента
- Адаптивные размеры шрифтов
- Правильные отступы и интервалы

#### `ImagePreview`
- Обработка ошибок загрузки
- Красивые тени и скругления
- Поддержка подписей
- Адаптивные размеры

#### `GalleryPreview`
- Три макета: сетка, кладка, карусель
- Hover-эффекты
- Обработка пустых галерей
- Адаптивная сетка

#### `ButtonPreview`
- Два варианта: primary и outline
- Градиенты и анимации
- Hover-эффекты
- Центрирование

#### `FormPreview`
- Полнофункциональная форма
- Красивое оформление полей
- Градиентные кнопки
- Валидация

#### `DividerPreview`
- Элегантные разделители
- Градиентные линии
- Правильные отступы

## 📋 Инструкции по использованию

### Включение предпросмотра
1. Откройте визуальный редактор страницы
2. Нажмите кнопку "Предпросмотр" в шапке
3. Просмотрите готовую страницу
4. Нажмите "Редактировать" для возврата

### Особенности предпросмотра
- **Автообновление**: Изменения отображаются сразу
- **Полноэкранный режим**: Скрываются панели редактора
- **Индикаторы**: Показывается статус предпросмотра
- **Подсказки**: Для пустых страниц
