# Визуальный редактор страниц

Современный drag-and-drop редактор для создания и редактирования страниц сайта с поддержкой различных типов блоков.

## Возможности

### 🎨 Визуальное редактирование
- **Drag & Drop интерфейс** - перетаскивайте блоки для создания страниц
- **Живой предпросмотр** - видите результат в реальном времени
- **Три панели интерфейса**:
  - Слева: Палитра блоков
  - По центру: Рабочая область
  - Справа: Настройки выбранного блока

### 📦 Типы блоков

#### 1. Заголовок (Heading)
- Настраиваемый уровень (H1-H6)
- Выравнивание текста (лево, центр, право)
- Редактируемый текст

#### 2. Текст (Paragraph)
- Поддержка HTML разметки
- Богатое текстовое содержимое

#### 3. Изображение (Image)
- Загрузка по URL
- Альтернативный текст
- Подпись (опционально)

#### 4. Галерея (Gallery)
- Три макета: сетка, кирпичная кладка, карусель
- Множественные изображения
- Настраиваемые подписи

#### 5. Кнопка (Button)
- Настраиваемый текст и ссылка
- Два стиля: основная и контурная

#### 6. Форма (Form)
- Стандартная контактная форма
- Поля: имя, email, сообщение

#### 7. Разделитель (Divider)
- Визуальный разделитель между блоками

### 🔧 Функции редактора

#### Управление блоками
- **Добавление**: Перетащите блок из палитры в рабочую область
- **Переупорядочивание**: Перетащите блоки для изменения порядка
- **Редактирование**: Кликните на блок и настройте в правой панели
- **Удаление**: Кнопка удаления при наведении на блок

#### История изменений
- **Отмена/Повтор**: Кнопки Undo/Redo в шапке
- **Автосохранение**: Отслеживание несохраненных изменений
- **Предпросмотр**: Переключение между режимами редактирования и просмотра

## Как использовать

### 1. Открытие редактора
- Перейдите в **Админ-панель** → **Контент** → **Страницы**
- Выберите страницу из списка
- Нажмите **"Визуальный редактор"**

### 2. Создание страницы
1. **Добавьте блоки**: Перетащите нужные блоки из левой панели
2. **Настройте содержимое**: Кликните на блок и отредактируйте в правой панели
3. **Упорядочьте**: Перетащите блоки для изменения порядка
4. **Сохраните**: Нажмите кнопку "Сохранить" в шапке

### 3. Редактирование существующих страниц
- Редактор автоматически загружает существующий контент
- Все изменения сохраняются в базу данных
- Синхронизация с системой меню

## Интеграция с системой

### Синхронизация с меню
- Ссылки в меню автоматически обновляются
- Поддержка существующей структуры `page_content`
- Совместимость с системой навигации

### Совместимость
- Работает с существующей базой данных
- Сохраняет данные в таблице `page_content`
- Поддерживает все существующие функции админ-панели

## Технические детали

### Архитектура
- **React + TypeScript** - типобезопасность
- **@dnd-kit** - современная библиотека drag-and-drop
- **Tailwind CSS** - стилизация
- **Supabase** - интеграция с базой данных

### Структура данных
```typescript
interface PageData {
  id: string;
  title: string;
  blocks: Block[];
}

interface Block {
  id: string;
  type: 'heading' | 'paragraph' | 'image' | 'gallery' | 'button' | 'form' | 'divider';
  props: Record<string, any>;
}
```

### Компоненты
- `PageEditor` - основной компонент редактора
- `BlockPalette` - палитра доступных блоков
- `CanvasArea` - рабочая область
- `SettingsPanel` - панель настроек
- `BlockRenderer` - рендеринг блоков

## Советы по использованию

### 🎯 Лучшие практики
1. **Начните с заголовка** - добавьте H1 для главной темы страницы
2. **Используйте изображения** - визуальный контент привлекает внимание
3. **Группируйте контент** - используйте разделители для структуры
4. **Тестируйте на мобильных** - проверяйте отображение на разных устройствах

### ⚡ Быстрые действия
- **Дублирование блока**: Скопируйте настройки и создайте новый
- **Массовое редактирование**: Используйте поиск и замену в тексте
- **Предпросмотр**: Регулярно переключайтесь в режим просмотра

### 🔍 Отладка
- Проверяйте консоль браузера на ошибки
- Убедитесь, что изображения загружаются по корректным URL
- Проверяйте валидность HTML в текстовых блоках

## Поддержка

При возникновении проблем:
1. Проверьте консоль браузера на ошибки
2. Убедитесь в корректности URL изображений
3. Попробуйте обновить страницу
4. Обратитесь к администратору системы
