# Архитектура визуального редактора страниц

## Обзор системы

```
┌─────────────────────────────────────────────────────────────────┐
│                    АДМИН-ПАНЕЛЬ                                 │
├─────────────────────────────────────────────────────────────────┤
│  AdminPage.tsx                                                  │
│  ├── MenuManagement.tsx (управление меню)                      │
│  ├── PageContentManagement.tsx (управление контентом)           │
│  └── PageEditor.tsx (новый визуальный редактор)                 │
└─────────────────────────────────────────────────────────────────┘
```

## Компоненты визуального редактора

### 1. PageEditor (главный компонент)
```
PageEditor.tsx
├── Состояние редактора (EditorState)
├── Управление историей (Undo/Redo)
├── Drag & Drop контекст
└── Интеграция с базой данных
```

### 2. Три панели интерфейса

#### Левая панель: BlockPalette
```
BlockPalette.tsx
├── Список доступных блоков
├── Drag & Drop источники
└── Иконки и описания
```

#### Центральная панель: CanvasArea
```
CanvasArea.tsx
├── Рабочая область
├── Drop зона для блоков
├── SortableContext для переупорядочивания
└── Рендеринг блоков
```

#### Правая панель: SettingsPanel
```
SettingsPanel.tsx
├── Настройки выбранного блока
├── Формы редактирования
└── Валидация данных
```

### 3. Система блоков

#### Базовые типы блоков
```
types/page-editor.ts
├── BlockType (heading, paragraph, image, gallery, button, form, divider)
├── BaseBlock (id, type)
├── Специализированные блоки (HeadingBlock, ParagraphBlock, etc.)
└── PageData (id, title, blocks[])
```

#### Рендеринг блоков
```
BlockRenderer.tsx
├── Switch по типу блока
├── Специализированные компоненты
└── Поддержка всех типов блоков
```

#### Drag & Drop блоков
```
SortableBlock.tsx
├── useSortable hook
├── Визуальные индикаторы
├── Кнопки управления
└── Обработка событий
```

## Интеграция с существующей системой

### База данных
```
Supabase Integration
├── Таблица: page_content
├── Поля: page_name, section_name, content_type, content_value
├── Синхронизация с меню
└── Обратная совместимость
```

### События и коммуникация
```
Event System
├── open-content-for (переход к редактированию)
├── open-visual-editor (открытие визуального редактора)
├── open-blocks-picker (открытие палитры блоков)
└── Cross-component communication
```

## Поток данных

### 1. Загрузка страницы
```
MenuManagement → AdminPage → PageContentManagement → PageEditor
├── Выбор страницы
├── Загрузка данных из БД
├── Конвертация в PageData
└── Открытие редактора
```

### 2. Редактирование
```
User Actions → PageEditor → State Management
├── Drag & Drop блоков
├── Изменение настроек
├── Обновление состояния
└── История изменений
```

### 3. Сохранение
```
PageEditor → PageContentManagement → Supabase
├── Конвертация PageData в формат БД
├── Удаление старых записей
├── Вставка новых данных
└── Обновление интерфейса
```

## Технологический стек

### Frontend
- **React 18** - UI библиотека
- **TypeScript** - типизация
- **@dnd-kit** - drag & drop
- **Tailwind CSS** - стилизация
- **Lucide React** - иконки

### Backend
- **Supabase** - база данных
- **PostgreSQL** - хранение данных
- **Real-time** - синхронизация

### Утилиты
- **nanoid** - генерация ID
- **@dnd-kit/utilities** - утилиты drag & drop
- **@dnd-kit/sortable** - сортировка

- Оптимизированный рендеринг

- Интуитивный drag & drop интерфейс
