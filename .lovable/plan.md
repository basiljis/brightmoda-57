# Стабилизация Docker-сборки в Timeweb

## Что изменю
- Обновлю и закреплю базовый Node-образ со стабильной версией npm вместо проблемной версии npm из текущего Alpine-образа.
- Уберу устаревшую настройку `NPM_CONFIG_PRODUCTION`, которая создаёт предупреждение и неоднозначно влияет на dev-зависимости.
- Явно установлю dev-зависимости, ограничу параллельные загрузки npm для экономии памяти и сохраню проверку наличия Vite до сборки.
- Добавлю аргумент очистки кэша сборки, чтобы Timeweb не запускал повторно старый слой без Vite.

## Проверка
- Выполню чистую установку по `package-lock.json` и проверку версии Vite.
- Проверю итоговую конфигурацию Docker Compose.

## Важно
После публикации изменений в Timeweb потребуется один раз запустить сборку без кэша. Нативные компиляторы добавлять не буду: лог не показывает ошибок нативных модулей, а лишние пакеты увеличат образ и расход памяти.
