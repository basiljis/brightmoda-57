# Мультитенантность — план

## Готово (этап 1)
- Таблицы `tenants` и `tenant_members`, привязка `tenant_id` ко всем таблицам содержимого.
- Правила доступа: публичный просмотр, запись — только участникам активного проекта (restrictive-политики).
- Функция `create_tenant` — самостоятельное создание проекта с пробным периодом 7 дней.
- Автоматическая фильтрация всех запросов по текущему проекту (обёртка `supabase.from`).
- Определение проекта по адресу `/nameproject`, `basename` роутера.
- Страница `/projects` — создание и список своих проектов.
- Баннер пробного периода и режим «только просмотр» после его окончания.
