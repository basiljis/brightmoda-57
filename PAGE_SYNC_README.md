# Система синхронизации страниц сайта и админ-панели

## 📋 Обзор

Система синхронизации обеспечивает автоматическое обнаружение и управление контентом всех страниц сайта через админ-панель. Это позволяет поддерживать консистентность между реальными страницами сайта и их контентом в базе данных.

## 🎯 Основные возможности

### 1. **Автоматическое обнаружение страниц**
- Система автоматически сканирует все маршруты сайта
- Определяет статус синхронизации каждой страницы
- Показывает статистику синхронизации в реальном времени

### 2. **Управление контентом**
- Создание контента для новых страниц одним кликом
- Визуальный редактор для редактирования контента
- Автоматическая синхронизация изменений

### 3. **Мониторинг статуса**
- Прогресс-бар синхронизации
- Цветовая индикация статуса
- Рекомендации по улучшению

## 🏗️ Архитектура системы

### Компоненты

#### `PageSyncManager`
- **Назначение**: Основной компонент управления синхронизацией
- **Функции**:
  - Отображение списка всех страниц сайта
  - Создание контента для новых страниц
  - Открытие визуального редактора
  - Массовое создание контента

#### `PageSyncStatus`
- **Назначение**: Отображение статуса синхронизации
- **Функции**:
  - Прогресс-бар синхронизации
  - Статистика по страницам
  - Рекомендации по улучшению
  - Автообновление статуса

#### `PageContentManagement`
- **Назначение**: Управление контентом страниц
- **Функции**:
  - Переключение между режимами (синхронизация/редактор)
  - Выбор страницы для редактирования
  - Интеграция с визуальным редактором

## 🔄 Процесс синхронизации

### 1. **Обнаружение страниц**
```typescript
const SITE_PAGES = [
  { path: '/', name: 'Главная', component: 'HomePage' },
  { path: '/about', name: 'О нас', component: 'AboutPage' },
  // ... другие страницы
];
```

### 2. **Проверка статуса**
- Запрос к базе данных для получения существующего контента
- Сравнение с определенными страницами сайта
- Подсчет статистики синхронизации

### 3. **Создание контента**
```typescript
const defaultContent = [
  {
    page_name: pageName,
    section_name: 'page_layout',
    content_type: 'json',
    content_value: 'default',
    display_order: 0,
    is_active: true
  },
  {
    page_name: pageName,
    section_name: 'title',
    content_type: 'html',
    content_value: `<h1>${page.name}</h1>`,
    display_order: 1,
    is_active: true
  }
];
```

## 🎨 Интерфейс пользователя

### Режим синхронизации
- **Список страниц**: Отображение всех страниц с их статусом
- **Действия**: Создание контента, редактирование, просмотр
- **Статистика**: Общая информация о синхронизации

### Режим редактора
- **Выбор страницы**: Dropdown с доступными страницами
- **Визуальный редактор**: Открытие редактора для выбранной страницы
- **Просмотр контента**: Отображение текущего контента страницы

## 📈 Мониторинг и аналитика

### Индикаторы статуса
- 🟢 **Отлично** (90%+ синхронизировано)
- 🟡 **Хорошо** (70-89% синхронизировано)
- 🔴 **Требует внимания** (<70% синхронизировано)

### Метрики
- Общее количество страниц
- Количество синхронизированных страниц
- Количество несинхронизированных страниц
- Процент синхронизации

## 🚀 Использование

### 1. **Просмотр статуса**
1. Перейдите в Админ-панель → Контент → Страницы
2. Просмотрите общий статус синхронизации в верхней части
3. Изучите список всех страниц сайта

### 2. **Создание контента**
1. Найдите страницу без контента (красный индикатор)
2. Нажмите "Создать контент"
3. Система автоматически создаст базовую структуру

### 3. **Редактирование контента**
1. Переключитесь в режим "Редактор контента"
2. Выберите страницу из списка
3. Нажмите "Визуальный редактор"
4. Отредактируйте контент с помощью drag-and-drop интерфейса

### 4. **Массовое создание**
1. В режиме синхронизации нажмите "Создать контент для всех страниц"
2. Система создаст базовый контент для всех несинхронизированных страниц

## 🔧 Технические детали

### База данных
- Таблица `page_content` для хранения контента страниц
- Поля: `page_name`, `section_name`, `content_type`, `content_value`, `display_order`
- Автоматическое создание записей при синхронизации

### События
- `open-visual-editor-for`: Открытие визуального редактора для конкретной страницы
- Автоматическое обновление статуса при изменениях

### Производительность
- Кэширование статуса синхронизации
- Ленивая загрузка контента страниц
- Оптимизированные запросы к базе данных
